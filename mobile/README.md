# AirLens Mobile

Expo ve React Native ile hazırlanmış AirLens mobil uygulama iskeletidir. Backend API'den özet metrikleri ve havayolu analizlerini okuyarak dashboard gösterir.

## Çalıştırma

```bash
cd mobile
npm install
EXPO_PUBLIC_API_URL=http://127.0.0.1:8000 npm start
```

Fiziksel cihaz kullanırken `127.0.0.1` yerine bilgisayarınızın yerel ağ IP adresini kullanın.
